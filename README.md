E-commerce Website

Project Description

This is a simple E-commerce website built using HTML and CSS. It provides a clean and responsive design to showcase and sell products online.

Features

Home Page: Displays featured products and promotions.

Product Listing Page: Grid layout showcasing multiple products.

Product Details Page: Detailed view with images, description, and price.

Shopping Cart: Allows users to add and remove items.

Checkout Page: Simple checkout form for order completion.

Responsive Design: Works on desktops, tablets, and mobile devices.

Technologies Used

HTML5: Structure of the website.

CSS3: Styling and responsiveness.

Google Fonts: Custom typography.

FontAwesome: Icons for better UI.

Installation

Clone the repository:

git clone https://github.com/Drhamza0/HTML-CSS-Ecommerce-Website.git

Open index.html in your browser.

Usage

Navigate through pages using the navbar.

Browse products and view details.

Add items to the cart and proceed to checkout.
